##  Objetivo do Projeto
Um projeto prático desenvolvido com o objetivo de dominar os conceitos fundamentais de **Manipulação do DOM (Document Object Model)** em JavaScript Puro (Vanilla JS). Este projeto faz parte da trilha inicial de Front-End da **Alura**.

O projeto simula um jogo de perguntas e resposta.

---

##  Tecnologias Utilizadas

*   **HTML5:** Estruturação semântica e aplicação de boas práticas com atributos customizados.
*   **CSS3:** Estilização moderna e organização do layout do painel com  CSS-BEM.
*   **JavaScript :** Lógica de programação, escuta de eventos e alteração dinâmica do DOM.

---

##  Conceitos de JavaScript Treinados

Este projeto foi desenhado especificamente para consolidar o aprendizado em manipulação de páginas web. Os principais tópicos aplicados foram:

*   **Seleção Avançada de Elementos:** Utilização de `document.querySelectorAll()` para capturar múltiplos elementos de forma eficiente.
*   **Data-Attributes (`data-*`):** Uso de atributos de dados customizados no HTML para desacoplar a lógica do JavaScript das classes de estilização (CSS), blindando o código contra quebras visuais.
*   **Manipulação de Eventos:** Implementação de `addEventListener` combinado com o método `forEach` para monitorar múltiplos botões simultaneamente com poucas linhas de código.
*   **Navegação Inteligente no DOM:** Aplicação do método moderno `.closest()` para encontrar elementos ancestrais e interagir apenas com o bloco de componentes correto, evitando o uso de caminhos rígidos como `parentNode`.
